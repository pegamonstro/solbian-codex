# User Interface

## Phase I Primary Interface

The primary interface consists of two tabs or equivalent views:

### Solace

The conversational environment.

Purpose:

- conduct the living JD ↔ Solace dialogue;
- browse conversation history;
- continue discussions.

### Codex Solbian

The Codex inspection environment.

Purpose:

- browse the Codex;
- inspect chapters/scrolls/sections;
- inspect revision history;
- inspect provenance where available.

The Codex view is read-only for ordinary use.

## Design Direction

The interface should be:

- minimal;
- calm;
- legible;
- predictable;
- content-first;
- easy to inspect.

Avoid dashboards and decorative complexity that do not support understanding.

## Administrative Information

Processing status, proposals, diagnostics, and engine internals may be available through a restrained administrative/development surface if needed.

They are not part of the primary conceptual experience.
