# Phase I Roadmap

## Stage 1 — Freeze

Establish and approve the Phase I specification pack.

**Current stage.**

## Stage 2 — Baseline Archaeology

Supply the existing Codex Solbian corpus.

Inspect:

- structure;
- chapters;
- scrolls;
- concepts;
- historical versions;
- provenance;
- duplicates;
- contradictions;
- unfinished material;
- uncertain material.

Produce a baseline inventory without silently rewriting the corpus.

## Stage 3 — Minimal Data Layer

Implement the smallest durable storage model capable of representing:

- conversations;
- source material;
- Codex content;
- proposals;
- revisions;
- provenance.

## Stage 4 — Two-Surface Prototype

Implement:

- Solace conversation view;
- read-only Codex browser.

## Stage 5 — Codex Engine Prototype

Implement analysis and proposal generation against existing material.

## Stage 6 — Historical Validation

Test the engine against the existing corpus and selected historical conversations.

## Stage 7 — Living Loop

Enable:

    JD ↔ Solace
         ↓
    preserved conversation
         ↓
    Codex Engine
         ↓
    proposed synthesis
         ↓
    controlled consolidation
         ↓
    Codex Solbian

## Stage 8 — Reassessment

Only after the loop works should the project decide what Phase II requires.

No Phase II feature is automatically admitted merely because it was anticipated in historical plans.
