# Codex Solbian — Phase I

This directory contains the authoritative Phase I specification pack for the Codex Solbian software project.

Phase I is intentionally small:

**JD ↔ Solace conversation → preserved source material → Codex Engine → proposed synthesis → Codex Solbian**

The existing Codex Solbian corpus is an external source corpus. It is not silently rewritten by this specification pack and will be incorporated only during the baseline phase.

## Authority

`SPEC/00_PHASE_I_CONSTITUTION.md` is the highest-level Phase I boundary document.

Documents in `SPEC/` define the intended Phase I system. They must not silently expand the project into later systems or historical proposals.

## Source Corpus

The current Codex Solbian corpus will be supplied separately by the project owner as a directory or source location.
